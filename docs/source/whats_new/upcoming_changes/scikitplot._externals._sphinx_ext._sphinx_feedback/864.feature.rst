- Page feedback adapts to any deployment: ``feedback_endpoint`` accepts a
  same-origin path (``/v1/feedback``) and, under
  ``feedback_endpoint_policy = "private-network"`` or ``"any"``, intranet and
  plain-HTTP services (the service mirrors this with
  ``FEEDBACK_ORIGIN_POLICY``); the feedback service gains a local ``git``
  provider (one commit per event, no network), GitHub Enterprise through
  ``api_url``, an HMAC-signed ``webhook`` provider with a reference Cloudflare
  Worker + D1 receiver, and ``custom`` Python adapters; service outcomes are
  logged to ``sphinx_feedback.service`` without comments, credit or addresses;
  and ``python -m scikitplot._externals._sphinx_ext._sphinx_feedback``
  generates counter snapshots (``aggregate``) and ready-to-paste settings
  (``init``).
